# Inglés II - Estrategias de Lectura Técnica y Morfología

Materia: [[Inglés II]]
Anterior: [[Inglés II - Comparativos, Superlativos y Oraciones Condicionales]]
Siguiente: [[Inglés II - Vocabulario de TI y Redacción Técnica]]

## Contexto y objetivo

La mayor parte de la bibliografía actualizada en computación se publica en inglés. Esta clase profundiza en las **estrategias de lectura comprensiva** (*skimming, scanning*, inferencia por contexto y referencia pronominal) junto con el análisis morfológico (**prefijos y sufijos**) para deducir el significado de palabras desconocidas sin depender constantemente del diccionario.

## 1. Estrategias de lectura en textos técnicos

1. **Skimming** (lectura global): leer título, resumen (*abstract*), subtítulos y primera oración de cada párrafo para identificar el tema central y el propósito del autor.
2. **Scanning** (lectura selectiva): localizar cifras, comandos, nombres de funciones, versiones o definiciones específicas.
3. **Referencia contextual** (*contextual reference*): identificar a qué sustantivo previo (*antecedente*) apuntan pronombres como *it, they, this, these, which, that*.
   - Ejemplo: *"A compiler translates source code into machine code. **It** also reports syntax errors."* (`It` = *a compiler*).
4. **Inferencia por contexto**: usar definiciones implícitas, ejemplos (*such as, for instance*) o contrastes (*unlike, however*) para deducir un término nuevo.

## 2. Afijos frecuentes en inglés técnico (Morfología)

Reconocer la raíz y los afijos permite identificar la categoría gramatical (sustantivo, verbo, adjetivo, adverbio) y el sentido:

### Prefijos comunes
| Prefijo | Significado | Ejemplos técnicos |
|---|---|---|
| `un-`, `in-`, `im-`, `dis-` | negación / opuesto | *unavailable, invalid, impossible, disconnect* |
| `re-` | repetición | *reboot, recompile, reconnect, overwrite* (*over-* = exceso) |
| `pre-` / `post-` | antes / después | *precondition, preprocessing, postorder* |
| `multi-` | múltiples | *multithreading, multitasking, multiplatform* |
| `sub-` | debajo / parte de | *subnet, subtree, subroutine* |

### Sufijos comunes
| Sufijo | Categoría resultante | Ejemplos técnicos |
|---|---|---|
| `-tion`, `-ment`, `-ness`, `-ity` | Sustantivo | *encryption, deployment, robustness, scalability* |
| `-er`, `-or` | Agente / dispositivo | *compiler, router, processor, debugger* |
| `-ize`, `-ify`, `-ate` | Verbo | *optimize, verify, authenticate* |
| `-able`, `-ible`, `-less`, `-ful` | Adjetivo | *scalable, compatible, wireless, useful* |
| `-ly` | Adverbio | *efficiently, automatically, securely* |

## 3. Repaso de falsos amigos (*False Friends*) en TI

- **library**: biblioteca / librería de software (no tienda de libros: *bookstore*).
- **support**: dar soporte / ser compatible con (no "soportar" emocionalmente: *tolerate*).
- **actually**: en realidad, de hecho (no "actualmente": *currently*).
- **exit**: salida (no "éxito": *success*).
- **save**: guardar / ahorrar (no "saber": *know*).

## Errores comunes

- Traducir palabra por palabra ignorando los sustantivos compuestos (*noun phrases*): en inglés el núcleo va al final (*"high-speed wireless network adapter"* = adaptador de red inalámbrica de alta velocidad).
- Confundir el antecedente de *this/which* en oraciones largas.

## Ejercicios propuestos

1. Deduce la categoría y significado de: *reusable, decryption, wireless, misconfiguration*.
2. Traduce el sintagma nominal: *"open-source relational database management system"*.

**Respuestas:**
1. *reusable* (adj.: reutilizable), *decryption* (sust.: descifrado), *wireless* (adj.: inalámbrico / sin cables), *misconfiguration* (sust.: configuración errónea).
2. "sistema de gestión de bases de datos relacionales de código abierto".

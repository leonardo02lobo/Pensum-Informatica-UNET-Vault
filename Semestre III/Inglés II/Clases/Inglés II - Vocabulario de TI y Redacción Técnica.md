## Contexto y objetivo

Como cierre de [[Inglés II]], esta clase integra el vocabulario especializado de Tecnologías de la Información (hardware, software, redes, bases de datos y seguridad) con pautas prácticas para redactar párrafos técnicos, resúmenes (*abstracts*) y correos electrónicos profesionales en inglés.

## 1. Glosario esencial de TI por áreas

| Área | Términos clave |
|---|---|
| **Hardware y Arquitectura** | *CPU, RAM, motherboard, storage, cache, peripheral, firmware, throughput* |
| **Software y Desarrollo** | *source code, compiler, bug, debugging, framework, library, deploy, release, repository* |
| **Redes y Nube** | *bandwidth, latency, packet, router, switch, firewall, cloud computing, endpoint* |
| **Bases de Datos** | *query, schema, primary key, table, backup, indexing, transaction* |
| **Seguridad** | *encryption, hashing, authentication, vulnerability, patch, malware, breach* |

## 2. Estructura de un párrafo técnico y un resumen (*Summary*)

Un párrafo técnico bien estructurado en inglés sigue el esquema **T-E-C**:
1. **Topic sentence** (oración temática): presenta la idea principal del párrafo.
2. **Explanation / Evidence** (desarrollo): explica el mecanismo, da ejemplos o compara opciones.
3. **Concluding sentence** (cierre): resume el impacto o enlaza con el siguiente tema.

**Ejemplo breve:**
> *"Version control systems are essential in modern software engineering. Tools such as Git allow teams to track code changes, create isolated branches, and merge contributions safely. Consequently, developers can collaborate efficiently without overwriting each other's work."*

## 3. Redacción de correos electrónicos formales en inglés

Estructura estándar para comunicarse con profesores, clientes o equipos internacionales:

```text
Subject: Question regarding Assignment 2 – Data Structures

Dear Professor [Last Name],

I hope this email finds you well. I am writing to ask about the deadline
for the second project in Estructura de Datos. Could you please clarify
whether the AVL tree must support deletion?

Thank you for your time and assistance.

Best regards,
[Your Full Name]
Informatics Engineering Student – UNET
```

**Expresiones útiles:**
- Apertura: *I am writing to inquire about...* / *I would like to inform you that...*
- Solicitud cortés: *Could you please...?* / *Would it be possible to...?*
- Cierre: *I look forward to hearing from you.* / *Sincerely,* / *Best regards,*

## Errores comunes

- Usar lenguaje demasiado informal en correos académicos (*"Hey prof, send me the PDF thx"*).
- Omitir la línea de asunto (*Subject*) o escribir párrafos sin oración temática clara.
- Traducir literalmente frases coloquiales del español al inglés (*"I make a question"* en lugar de *"I have a question"* o *"I would like to ask"*).

## Ejercicios propuestos

1. Relaciona cada término con su significado: *deploy, query, bandwidth, debugging*.
2. Redacta un correo corto (4–5 líneas) en inglés solicitando acceso a un repositorio de código a un compañero de equipo.

**Respuestas:**
1. *deploy* (desplegar/poner en producción), *query* (consulta a BD), *bandwidth* (ancho de banda), *debugging* (depuración de errores).
2. Ejemplo: *"Subject: Access to project repository. Hi [Name], could you please grant me write access to the GitHub repository for our Data Structures project? My username is [user]. Thanks in advance! Best, [Name]."*

# Inglés II - Comparativos, Superlativos y Oraciones Condicionales

Materia: [[Inglés II]]

## Contexto y objetivo

Evaluar alternativas tecnológicas (lenguajes, procesadores, algoritmos) exige saber **comparar** propiedades y expresar **condiciones lógicas** (*if-then*). Esta clase aborda los grados comparativo y superlativo de los adjetivos, los conectores de contraste y causa, y los condicionales cero, primero y segundo.

## 1. Comparativos y superlativos

| Tipo de adjetivo | Comparativo | Superlativo | Ejemplo |
|---|---|---|---|
| Corto (1 sílaba) | `adj + -er + than` | `the + adj + -est` | *faster than / the fastest* |
| Terminado en `-y` (2 síl.) | `adj - y + -ier + than` | `the + adj - y + -iest` | *easier than / the easiest* |
| Largo (2+ sílabas) | `more/less + adj + than` | `the most/least + adj` | *more reliable than / the most secure* |
| Irregulares | *good $\rightarrow$ better*, *bad $\rightarrow$ worse*, *far $\rightarrow$ farther/further* | *the best, the worst, the farthest* | *Better performance than v1.* |

Igualdad: `as + adjetivo + as` (*"C++ is not as easy as Python, but it is faster."*).

## 2. Conectores lógicos esenciales

- **Causa**: *because, since, as* (*"The build failed because a dependency was missing."*).
- **Contraste**: *but, however, although, whereas* (*"Although the algorithm is simple, it is slow for large inputs."*).
- **Resultado**: *so, therefore, consequently* (*"Memory was full; therefore, the process terminated."*).

## 3. Oraciones condicionales (0, 1 y 2)

| Tipo | Estructura | Uso | Ejemplo técnico |
|---|---|---|---|
| **Zero Conditional** | `If + Presente Simple, Presente Simple` | Verdades universales, reglas deterministas | *If you divide by zero, the program throws an exception.* |
| **First Conditional** | `If + Presente Simple, will/can/must + V` | Situaciones reales o probables en el futuro | *If the unit test fails, we will debug the module.* |
| **Second Conditional** | `If + Pasado Simple, would/could + V` | Hipótesis poco probables o imaginarias | *If we had more RAM, the simulation would run faster.* |

## Errores comunes

- Mezclar *more* con *-er*: ~~more faster~~ $\rightarrow$ **faster**.
- Usar *will* dentro de la cláusula con *if* en el primer condicional: ~~If it will rain~~ $\rightarrow$ **If it rains**.
- Usar *although* y *but* juntos en la misma oración: ~~Although it is fast, but it uses much memory~~ $\rightarrow$ **Although it is fast, it uses much memory**.

## Ejercicios propuestos

1. Forma el comparativo y superlativo de: *efficient, fast, bad, heavy*.
2. Completa (First Conditional): *"If the user ___ (enter) an invalid PIN, the system ___ (lock) the account."*
3. Completa (Second Conditional): *"If I ___ (know) Rust, I ___ (rewrite) that service."*

**Respuestas:**
1. *more efficient / the most efficient*; *faster / the fastest*; *worse / the worst*; *heavier / the heaviest*.
2. *enters* / *will lock*.
3. *knew* / *would rewrite*.

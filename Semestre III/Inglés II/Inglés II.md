## Apuntes

### Descripción general y objetivos

Inglés II continúa [[Inglés I]] y afianza la **comprensión lectora de textos técnicos en inglés** y la comunicación básica oral y escrita, orientadas a la Ingeniería Informática. No hay Material propio en el vault; el siguiente contenido es referencial (verificar con el programa oficial de la UNET).

Objetivos típicos: leer documentación técnica (manuales, APIs, artículos), escribir textos breves y correos formales, y ampliar el vocabulario de computación.

### Contenido programático (referencial)

1. **Tiempos verbales**: presente simple y continuo, pasado simple y continuo, presente perfecto, futuro (`will`, `going to`).
2. **Modales**: can, could, must, should, may, might.
3. **Voz pasiva** en descripciones de procesos ("the data is stored in...").
4. **Comparativos y superlativos**, cuantificadores, artículos.
5. **Conectores y cláusulas**: and/but/because/although; condicionales cero, primero y segundo.
6. **Estrategias de lectura**: skimming, scanning, inferencia por contexto, prefijos y sufijos, cognados y falsos amigos.
7. **Vocabulary for IT**: hardware, software, network, database, cloud, security, debugging.
8. **Escritura**: párrafo, resumen, correo electrónico, descripción de un proceso.

### Conceptos clave y estructuras

```
Present Perfect:   have/has + past participle      "I have installed the package."
Passive voice:     be + past participle              "The file is compressed."
First conditional: If + present, will + base verb    "If the test fails, we will fix it."
Comparative:       adj + -er / more + adj + than     "Faster than", "more reliable than"
```

Vocabulario útil: *bug* (error), *deploy* (desplegar), *query* (consulta), *bandwidth* (ancho de banda), *library* (librería, no "librería" de libros), *to run* (ejecutar).

### Ejemplo breve

"The server was restarted because the memory had been exhausted." (pasiva + pasado perfecto). Traducción: "El servidor fue reiniciado porque la memoria se había agotado."

### Relación con otras materias

Secuencia: [[Inglés I]] -> Inglés II (no desbloquea otras según el pensum). Es útil en todas las materias técnicas: bibliografía y documentación de [[Programación II]], manuales de [[Fundamentos de Lógica Digital]], etc.

### Evaluación y consejos de estudio

- Leer cada día algo corto en inglés (documentación, noticias tecnológicas).
- Llevar un glosario personal de términos técnicos.
- Practicar con textos de APIs y README de proyectos de software.
- Ponderación y exámenes: verificar con el programa oficial.

### Bibliografía recomendada

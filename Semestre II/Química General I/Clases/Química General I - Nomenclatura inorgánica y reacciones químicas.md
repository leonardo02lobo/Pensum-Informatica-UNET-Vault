# Química General I - Nomenclatura inorgánica y reacciones químicas

Materia: [[Química General I]]
Anterior: [[Química General I - Enlace químico]]
Siguiente: [[Química General I - Estequiometría]]

## Contexto y objetivo
Para hablar de química hay que nombrar compuestos y escribir reacciones balanceadas. Esta nota presenta números de oxidación, nomenclatura de óxidos, hidróxidos, ácidos, sales e hidruros, los tipos de reacción y el balanceo (tanteo, algebraico y redox). Objetivo: pasar de nombre a fórmula y viceversa, y balancear cualquier ecuación básica. (Se muestra la nomenclatura tradicional y la IUPAC/Stock; verificar con el programa oficial cuál prefiere el curso.)

## 1. Número de oxidación (NO)
Carga que tendría un átomo si todos los enlaces fueran iónicos. Reglas:
1. Elemento libre: 0 (O₂, Fe, S₈).
2. Ion monoatómico: su carga.
3. H: +1 (excepto hidruros metálicos: -1). O: -2 (excepto peróxidos: -1).
4. Metales alcalinos +1, alcalinotérreos +2, Al +3, F siempre -1.
5. La suma de NO en un compuesto neutro es 0; en un ion poliatómico, su carga.

Ejemplo: Mn en KMnO₄: +1 + x + 4(-2) = 0 → x = +7. Cr en Cr₂O₇²⁻: 2x - 14 = -2 → x = +6.

## 2. Nomenclatura
| Tipo | Fórmula general | Ejemplo (tradicional / Stock) |
|---|---|---|
| Óxido básico | M₂Oₙ (metal + O) | Na₂O óxido de sodio; FeO óxido ferroso / óxido de hierro(II); Fe₂O₃ óxido férrico / óxido de hierro(III) |
| Óxido ácido (anhídrido) | no metal + O | CO₂ dióxido de carbono; SO₃ trióxido de azufre; N₂O₅ pentóxido de dinitrógeno |
| Peróxido | contiene O₂²⁻ | H₂O₂ peróxido de hidrógeno |
| Hidróxido (base) | M(OH)ₙ | NaOH hidróxido de sodio; Ca(OH)₂; Fe(OH)₃ hidróxido de hierro(III) |
| Hidruro metálico | MHₙ | NaH hidruro de sodio |
| Hidrácido | H + no metal (grupos 16 y 17) | HCl(ac) ácido clorhídrico; H₂S(ac) ácido sulfhídrico |
| Oxácido | H + no metal + O | HNO₃ ácido nítrico; H₂SO₄ ácido sulfúrico; H₃PO₄ ácido fosfórico; H₂CO₃ ácido carbónico; HClO₄ ácido perclórico |
| Sal binaria | metal + no metal | NaCl cloruro de sodio; FeCl₃ cloruro férrico |
| Oxisal | catión + anión de oxácido | CaCO₃ carbonato de calcio; Na₂SO₄ sulfato de sodio; KNO₃ nitrato de potasio |

Prefijos/sufijos tradicionales para halógenos: hipo-...-oso (ClO⁻ hipoclorito), -oso (ClO₂⁻ clorito), -ico (ClO₃⁻ clorato), per-...-ico (ClO₄⁻ perclorato). Oxácido -ico → oxianión -ato; oxácido -oso → oxianión -ito.

Iones comunes: NH₄⁺ amonio, OH⁻ hidróxido, NO₃⁻ nitrato, SO₄²⁻ sulfato, CO₃²⁻ carbonato, PO₄³⁻ fosfato.

**Formulación**: se cruzan las cargas. Ejemplo: sulfato de aluminio: Al³⁺ y SO₄²⁻ → Al₂(SO₄)₃.

## 3. Tipos de reacciones
- **Síntesis**: A + B → AB (2 Mg + O₂ → 2 MgO).
- **Descomposición**: AB → A + B (2 H₂O₂ → 2 H₂O + O₂).
- **Desplazamiento simple**: A + BC → AC + B (Zn + CuSO₄ → ZnSO₄ + Cu; requiere que A sea más reactivo según la serie de actividad).
- **Doble desplazamiento**: AB + CD → AD + CB; incluye precipitación (AgNO₃ + NaCl → AgCl↓ + NaNO₃) y neutralización.
- **Neutralización**: ácido + base → sal + agua (HCl + NaOH → NaCl + H₂O).
- **Combustión**: hidrocarburo + O₂ → CO₂ + H₂O.
- **Redox**: transferencia de electrones; oxidación = pérdida (aumenta NO), reducción = ganancia (disminuye NO); el agente oxidante se reduce y el reductor se oxida.

Ácidos y bases (Arrhenius): ácido libera H⁺ en agua; base libera OH⁻. Brønsted-Lowry: ácido dona protón, base lo acepta. Ácidos fuertes: HCl, HBr, HI, HNO₃, H₂SO₄, HClO₄; bases fuertes: hidróxidos de grupos 1 y Ca, Sr, Ba.

## 4. Balanceo de ecuaciones
La ley de conservación de la masa exige el mismo número de átomos de cada elemento a ambos lados.

**Tanteo**. C₃H₈ + O₂ → CO₂ + H₂O: balancear C (3 CO₂), luego H (4 H₂O) y por último O: 3·2 + 4 = 10 O → 5 O₂.
$$\text{C}_3\text{H}_8 + 5\,\text{O}_2 \to 3\,\text{CO}_2 + 4\,\text{H}_2\text{O}$$

**Algebraico**. $a\,\text{Al} + b\,\text{HCl}\to c\,\text{AlCl}_3 + d\,\text{H}_2$: Al: a = c; H: b = 2d; Cl: b = 3c. Con a = 1: c = 1, b = 3, d = 3/2 → multiplicar por 2: 2 Al + 6 HCl → 2 AlCl₃ + 3 H₂.

**Redox (ion-electrón, medio ácido)**, ejemplo $\text{MnO}_4^- + \text{Fe}^{2+}\to\text{Mn}^{2+}+\text{Fe}^{3+}$:
1. Semirreacciones: MnO₄⁻ → Mn²⁺; Fe²⁺ → Fe³⁺.
2. Balancear O con H₂O y H con H⁺: MnO₄⁻ + 8H⁺ → Mn²⁺ + 4H₂O.
3. Balancear carga con e⁻: MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O; Fe²⁺ → Fe³⁺ + e⁻.
4. Igualar electrones (×5 la segunda) y sumar: MnO₄⁻ + 8H⁺ + 5Fe²⁺ → Mn²⁺ + 4H₂O + 5Fe³⁺.
En medio básico, se neutralizan los H⁺ añadiendo OH⁻ a ambos lados.

## Errores comunes
- Cambiar subíndices para balancear (solo se cambian coeficientes).
- Olvidar que el H₂O₂ tiene O con NO -1.
- Confundir sulfato/sulfito, nitrato/nitrito.
- No simplificar coeficientes (2, 4, 6 → 1, 2, 3).
- No verificar la carga en reacciones iónicas.

## Ejercicios propuestos
1. Nombra Fe₂(SO₄)₃. (sulfato de hierro(III) o sulfato férrico)
2. Formula el hidróxido de calcio y el ácido fosfórico. (Ca(OH)₂; H₃PO₄)
3. Balancea Fe + O₂ → Fe₂O₃. (4 Fe + 3 O₂ → 2 Fe₂O₃)
4. NO del N en NH₄⁺ y HNO₃. (-3; +5)
5. Balancea KMnO₄ + HCl → KCl + MnCl₂ + Cl₂ + H₂O. (2, 16, 2, 2, 5, 8)

## Conexiones
- Los coeficientes balanceados son la base de la [[Química General I - Estequiometría]].
- Ácidos y bases se usan en las disoluciones ([[Química General I - Disoluciones y unidades de concentración]]) y son tema de contaminación en [[Ecología y Contaminación Ambiental]] (lluvia ácida).

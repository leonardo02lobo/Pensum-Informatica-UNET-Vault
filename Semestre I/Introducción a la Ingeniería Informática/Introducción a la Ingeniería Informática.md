## Apuntes

### Descripción general y objetivos
Materia de orientación que presenta la **carrera, el perfil del ingeniero informático y los fundamentos tecnológicos**: qué es la informática, cómo funcionan los computadores, redes e Internet, datos y bases de datos, y el impacto de la tecnología en organizaciones y sociedad. Prepara el camino para [[Teoría General de Sistemas]]. Programa oficial: verificar.

### Contenido programático (según el Material; verificar con el programa oficial)
1. **Informática y computación**: definiciones, historia y generaciones de computadores, áreas de la ingeniería informática.
2. **Tecnología y sociedad**: la tecnología en los negocios y en la vida cotidiana, transformación digital, teletrabajo, ética.
3. **Internet**: red de redes, protocolos TCP/IP (IP y TCP), modelo cliente/servidor, servicios (web, correo), direcciones IP y DNS.
4. **Páginas web**: qué es y para qué sirve una página web (documento multimedia sobre WWW accesible con navegador); HTML, diseño y publicación.
5. **Administración de datos**: archivos convencionales, definición y ventajas de una base de datos (DB), sistema manejador de bases de datos (DBMS), administrador de bases de datos (DBA).
6. **Perfil profesional y campo laboral**: desarrollo de software, redes, bases de datos, gestión de proyectos, seguridad.

### Conceptos clave
- **Dato / información / conocimiento**: dato bruto, dato procesado con significado, información aplicada.
- **Red de computadoras**: equipos conectados para compartir información, recursos y servicios.
- **TCP/IP**: familia de protocolos; IP direcciona y encamina paquetes, TCP garantiza entrega ordenada y fiable.
- **Cliente/servidor**: servidores ofrecen información; clientes la solicitan.
- **DBMS**: software que gestiona la creación, consulta y seguridad de una DB (ver [[Base de Datos I]]).
- **Redundancia e inconsistencia**: problemas de los archivos convencionales que resuelve una DB.

### Esquema: petición web

Navegador (cliente) --DNS--> IP del servidor --HTTP/TCP--> Servidor web --> HTML/CSS/JS --> Navegador

### Ejemplo breve
Ventajas de una DB frente a archivos: menor redundancia, integridad, acceso concurrente, seguridad centralizada, independencia de datos.

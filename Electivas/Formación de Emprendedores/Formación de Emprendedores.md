# Formación de Emprendedores

Opción de [[Electivas]].

## Descripción
Desarrolla la mentalidad y las herramientas para crear empresas, en especial de base tecnológica: identificación de oportunidades, validación de ideas, modelo de negocio y plan de empresa. Objetivo: que el estudiante estructure un proyecto emprendedor viable.

## Temario típico (verificar con el programa oficial)
1. El emprendedor: perfil, motivación, riesgo y ética.
2. Generación y evaluación de ideas; análisis del mercado y la competencia.
3. Modelo de negocio (Canvas) y propuesta de valor; Lean Startup, MVP.
4. Plan de negocios: mercadeo, operaciones, organización, aspectos legales.
5. Plan financiero: inversión, costos, punto de equilibrio, flujo de caja, VAN y TIR.
6. Financiamiento: capital propio, ángeles, capital de riesgo, financiamiento público; presentación (pitch).

## Fórmulas
```
Punto de equilibrio (unidades) = Costos fijos / (Precio - Costo variable unitario)
VAN = sum_{t=0..n} FCt / (1+i)^t
```

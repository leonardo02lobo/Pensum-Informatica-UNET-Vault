# Gerencia de Proyectos

Opción de [[Electivas]] · [[Fuentes Oficiales UNET]].

**Código oficial:** `0423810` / `8212` · **Unidades de crédito:** 3 UC (3 h/s) · **Área:** Gerencial y Desarrollo de Sistemas

## Descripción
Métodos para planificar, ejecutar y controlar proyectos, con base en el PMBOK y metodologías ágiles; aplicable a proyectos de software e infraestructura.

## Temario típico (verificar con el programa oficial)
1. Ciclo de vida del proyecto, interesados y acta de constitución.
2. Alcance y WBS; cronograma: PERT/CPM y diagrama de Gantt.
3. Costos y presupuesto; valor ganado (EVM).
4. Calidad, riesgos, adquisiciones, comunicaciones y recursos humanos.
5. Herramientas: MS Project, Jira, Trello, GanttProject.
6. Enfoques ágiles y gestión híbrida.

## Fórmulas
```
PERT: te = (o + 4m + p) / 6 ;  sigma = (p - o) / 6
VP = % avance * presupuesto ; VG = valor ganado ; CR = costo real
CPI = VG / CR ;  SPI = VG / VP ;  EAC = BAC / CPI
```

# Ingeniería en Informática UNET · Obsidian Vault

Vault de conocimiento en **Obsidian** estructurado alrededor del pensum completo de **Ingeniería en Informática de la UNET** (Universidad Nacional Experimental del Táchira), diseñado para explorar materias, prelaciones, temas de clase y conexiones entre asignaturas desde la vista de grafo.

## Estructura del Vault

- **`Pensum Ingeniería Informática UNET.md`**: Mapa de contenido (MOC) principal con los 10 semestres y las electivas.
- **`Recursos Drive UNET.md`**: Índice maestro de material recopilado desde Google Drive, stack de herramientas y guía/plantilla para agregar nuevo conocimiento.
- **`Semestre I/` a `Semestre X/`**: Carpetas por semestre con cada asignatura.
- **`Electivas/`**: 13 asignaturas electivas del pensum.
- Dentro de cada asignatura:
  - `<Materia>.md`: Ficha principal con prelaciones, materias que desbloquea, contenido programático, conceptos clave, bibliografía y recursos.
  - `Clases/`: Notas detalladas por tema, encadenadas con enlaces `Anterior:` / `Siguiente:`, ejemplos resueltos, errores comunes, ejercicios propuestos y sección `## Conexiones` (`[[...]]`).
  - `Material/` *(excluido de Git por tamaño)*: PDFs, presentaciones, guías y material de apoyo local.

## Contenido

- **54** materias con carpetas `Clases/` completas
- **478** notas Markdown interconectadas mediante wikilinks (`[[...]]`)

## Cómo usarlo en Obsidian

1. Clona este repositorio:
   ```bash
   git clone <URL-DEL-REPO>
   ```
2. Abre **Obsidian** → *Open folder as vault* → selecciona la carpeta del repositorio.
3. Abre la **Vista de Grafo** (`Ctrl + G`) para navegar las conexiones entre semestres, prelaciones y temas.
4. Empieza desde `Pensum Ingeniería Informática UNET.md`.
